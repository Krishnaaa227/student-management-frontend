# 🎓 Student Management System - Frontend

React.js frontend for the Student Management System.

## Tech Stack

- React.js
- React Router DOM
- Axios
- Bootstrap
- React Icons
- Framer Motion
- Recharts
- React Toastify

## Features

- Login
- Register
- Dashboard
- Student Management
- Course Management
- Responsive Design
- JWT Authentication
- Excel Export
